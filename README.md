## How to install

### In ChatGPT

1. Download the zip of the skill you want.
2. In ChatGPT, open **Skills**, click **Create**, then **Upload from your computer**, and pick the zip.
3. Use it: type **@** in the chat box and pick the skill, or just ask for the job and ChatGPT picks it up.

Skills are on ChatGPT Business, Enterprise and Edu, and rolling out to more plans. If you do not see **Skills** yet, use a Project instead: create a new Project, open its instructions, and paste in the text of the skill's `SKILL.md` (everything under the second `---` line). It works the same way inside that Project.

### In Claude

- **Skills from the `chatgpt` folder:** they use the same open `SKILL.md` format, so the same zip works in Claude too. Upload it in Claude under Settings, Capabilities, Skills.
- **youtube-skill:** download `youtube-skill.md`, open the Claude desktop app, click the **Code** tab, drag the file in and type **set this up**. Claude installs everything and tells you when it is ready.

## What is inside each skill

Every skill is one folder with a `SKILL.md` file: a name, a one-line description of when to use it, and plain instructions. Open any of them and read exactly what it tells the AI to do. Nothing is hidden and nothing runs in the background.
