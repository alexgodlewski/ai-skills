# Meta Ads

Three tools in one skill: the **Ad Library Scraper**, the **Ad Writer** and the **Creative Tool**. Start with the website. If the person's own ad account is connected (or they drop in an export), use it to rewrite what is live and to say where the budget should go.

## 0. Start

The website is what the person typed after `/meta-ads`. If there is none, ask for it in one line and wait.

Open the website. Write down in one short block: what they sell, to whom, where, the price level, the main offer, and what makes them different. Name the industry in plain words (for example "dentists in Austin" or "online fitness coaching"). Ask one question only if something important is missing (for example the country they sell in).

## 1. Ad Library Scraper

The public Meta Ad Library is at facebook.com/ads/library. Anyone can open it. It shows ads currently running on Facebook, Instagram and Messenger, plus each ad's start date.

1. **Find 5 to 10 real competitors.** Search the web for the main product plus the place. Take the businesses that show up with ads, or that rank at the top. Include a few from the same industry in other cities if the local list is short. Say which ones you picked and why.
2. **Open each one's ads.** For each competitor, search their name in the Ad Library (country: where the person sells, category: all ads). Open their page's ads and record each active ad:
   - the start date ("Started running on"), so you can work out how many days it has run;
   - the format: single image, video, carousel, or text only;
   - the primary text, headline, and call to action button;
   - the landing page it sends people to (open it and note what the first screen says);
   - how many ads use the same creative, if the library shows it.
3. **Pick the likely winners.** An ad that has run for 30 days or more, and is still active, is probably making money, because advertisers turn off ads that lose. Ads with many copies or many versions are another sign. Say plainly that this is a strong hint and not proof: the library does not show spend, clicks or sales for most ads.
4. **If you cannot open the library from here,** use one of these and say which:
   - **A browser tool.** The library is a live web app, so a browser tool works best. Scroll to load more ads.
   - **Meta's own ads connection,** if one is available in this session and it has an ad library search tool. Use it.
   - **The official Ad Library API** (graph.facebook.com, the `ads_archive` endpoint). It needs a Meta access token, and the person must first confirm their identity with Meta at facebook.com/ID. Ask them to set it up and give you the token. Be honest about its limit: for commercial ads it returns ads shown in the European Union and the UK. Ads shown only in other countries come back only if they are about politics or social issues. If the person sells outside Europe, the web library is the better route.
   - **Nothing works:** ask the person to open the library, search their competitors, and paste the ads or screenshots. Never invent ads.
5. **Collect as many as you honestly can.** The reel-style promise of "hundreds" depends on how many ads the competitors really run. Report the real number you found. If it is 40, say 40.
6. **Group what you found** in a short table, then write the patterns under it:
   - **Formats:** how many are image, video, carousel, text. Which format holds most of the long-running ads.
   - **Hooks:** the first line of the primary text, sorted into types (question, bold claim, number, story, problem call-out, offer, before and after, testimonial). Which type repeats.
   - **Offers and calls to action:** free trial, discount, free guide, book a call, shop now, learn more. Which repeat.
   - **Creative looks:** for example founder talking to camera, product on a plain background, screenshot, customer photo, meme style.
   - **The gap:** one angle or format nobody in the list uses.

## 2. Their own account

**If a Meta ads connection is available** (for example Meta's ads MCP, or any Ads Manager connection): list their ad accounts, ask which one, then read the last 30 days, or 90 if spend is small. Pull campaigns, ad sets and ads with spend, reach, clicks, cost per result and results, and the creative and text of each ad. Reading needs the person to log in and approve access first. Say so if the connection is not set up yet.

**If not,** ask them to export a report from Ads Manager (Reports, Export, as CSV or Excel, broken down by ad, with spend, results, cost per result, and CTR) and drop it in. If they have neither, skip this step and say what to connect or export next time.

Then:

- list the ads that work: results at a fair cost, and enough spend to trust it. Say if the numbers are too small to trust;
- list the ads that waste money: spend with no results, or a cost per result far above the account average;
- list ad fatigue: ads with high frequency and a falling click rate;
- say where to move the budget, in plain numbers ("move about 20% from ad set A to ad set B because..."). Say how sure you are. Small samples get small moves.

You only read the account. Never create, edit, pause or delete anything in it, even if the connection allows it: the person makes the changes.

## 3. Ad Writer

Rewrite their ads, or write new ones, for each main offer:

- **5 primary texts.** Each starts with one of the hook types that repeat among the long-running competitor ads. The first 125 characters are what shows before "See more", so the hook and the point go there.
- **5 headlines,** about 40 characters or fewer (count them).
- **3 descriptions,** about 30 characters or fewer.
- **The call to action button** to pick from Meta's list, with a reason.
- **One landing page note:** what the first screen of the page must say so it matches the ad.

Base them on two things: what already works in their own account, and what the competitor winners share. Where their own data and the competitor pattern disagree, say so and trust their own data. Do not copy a competitor's words. Take the structure (the hook type, the offer shape, the order of the points) and write new words about the person's real business. Mark which of the new ads to test first. Never claim results, prices or guarantees the business cannot back up.

## 4. Creative Tool

For each winning format from step 1, write a brief the person can hand to a designer or paste into an image maker:

- **Format and size:** for example 1080 x 1350 for the feed, 1080 x 1920 for stories and reels.
- **What is in the picture:** subject, setting, how close the camera is, colors, any text on the image (keep it short).
- **The first-second idea** if it is a video: what is seen and said.
- **An image prompt** ready to paste into an image maker, in plain words.
- **Why:** which competitor pattern it follows, and what is different about it.

Make 3 briefs for the strongest format and 1 for each other format worth testing. You write the briefs and prompts. You do not make the images yourself unless the person has an image tool connected and asks for it. Never put a real person's face or a competitor's logo in a prompt.

## 5. Hand over

Finish with: the top three changes to make this week, then the budget moves (if you had account data), then the ads, then the creative briefs, each in a clean block they can copy.

## Rules

- Never invent competitor ads, dates, results, spend or numbers. Say how many ads you really found.
- The Ad Library does not show spend or sales for most ads. Long-running is a hint, not proof.
- Do not copy a competitor's text word for word.
- Read-only on the ad account. Never change anything in it.
- Plain words. No jargon unless you explain it in the same sentence.
