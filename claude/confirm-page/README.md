# confirm-page (for Claude)

**Your lead books a call, then looks you up. This skill builds the page they land on, so they show up ready to buy.**

Most people thank the lead and stop. This skill uses that moment to answer the doubts that make people ghost. Type `/confirm-page` and your offer, and Claude writes:

- **The page copy and layout:** what to say first, and what to ask them to do (confirm, add to calendar, watch a video).
- **Proof sections with slots** for your real results, reviews and numbers. It never invents proof.
- **The videos to record,** with a short script outline for each, plus a first draft in your voice.
- **What to leave out,** so the page stays honest and does not hype.
- **A short version for DM bookings:** a confirmation message plus links to send, for people with no website.

**[Download confirm-page-skill.md](https://github.com/alexgodlewski/ai-skills/releases/latest/download/confirm-page-skill.md)**

## Install in Claude Code (30 seconds)

1. Open the Claude desktop app and click the **Code** tab.
2. Drag `confirm-page-skill.md` in and type **set this up**.
3. Type `/confirm-page` and your offer, for example: `/confirm-page a $4,000 3-month coaching program for personal trainers, calls booked from Instagram DMs`.

## Install in claude.ai (browser)

Open `SKILL.md` below, copy everything under the second `---` line, and paste it into a new Project's instructions at claude.ai. Then start a chat in that Project and describe your offer. It works the same way.
