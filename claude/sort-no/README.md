# sort-no (for Claude)

**I sorted 46,718 no's. This skill sorts yours.**

Most teams answer every no the same way. But "I can't right now" and "I already have someone" are two different people. Drop the last hundred people who said no into Claude, type `/sort-no`, and it does the work:

- **Takes the names out.** No names, handles, phone numbers or emails in the result.
- **Puts every no into one of six piles:** Busy, Later, Price, Fear, Trust and Real.
- **Shows the biggest pile,** with the exact words people used.
- **Writes one answer for each pile** in your own words, short, with one question.
- **Says which pile costs you the most calls.** Often it is not the biggest one.
- **Gives you the first ten people to write to.** It never sends anything. You do.

**[Download sort-no-skill.md](https://github.com/alexgodlewski/ai-skills/releases/latest/download/sort-no-skill.md)**

## Install in Claude Code (30 seconds)

1. Open the Claude desktop app and click the **Code** tab.
2. Drag `sort-no-skill.md` in and type **set this up**.
3. Type `/sort-no` and paste your no's, one line for each person.

## Install in claude.ai (browser)

Open `SKILL.md` below, copy everything under the second `---` line, and paste it into a new Project's instructions at claude.ai. Then start a chat in that Project and paste your no's. It works the same way.
