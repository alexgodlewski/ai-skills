# outcome-first (for Claude)

**Stop telling Claude how. Tell it what.**

The more you tell Claude how to do something, the worse it does. Describe the finished result in detail instead, and it can nail it on the first try. Most people get this backwards: one line about the result, a page about how to do it.

This skill flips it. Before Claude builds anything, it asks you the right questions about the finished result (who it is for, what done looks like, what it must include), writes a one-page brief, and builds it in one go when you say yes.

**[Download outcome-first-skill.md](https://github.com/alexgodlewski/ai-skills/releases/latest/download/outcome-first-skill.md)**

## Install (30 seconds)

1. Open the Claude desktop app and click the **Code** tab.
2. Drag `outcome-first-skill.md` in and type **set this up**.
3. Ask for anything, the way you always do: *Make me a landing page for my coffee roaster.* Or type `/outcome-first` and what you want.

Using Claude in the browser instead? Download [`outcome-first-claude.zip`](https://github.com/alexgodlewski/ai-skills/releases/latest/download/outcome-first-claude.zip) and upload it under Settings, Capabilities, Skills.
