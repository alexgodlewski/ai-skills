# first-skill

**The first skill anyone should build, built with you in a few minutes.**

Tell Claude one task you do every day. It does the task with you, step by step, in Claude Code, using your connected tools like Gmail, Google Calendar and Google Drive. Then it saves the whole thing as a skill. Tomorrow you say **run** and the name of the skill, and the work runs without you walking through it again.

**[Download first-skill-skill.md](https://github.com/alexgodlewski/ai-skills/releases/latest/download/first-skill-skill.md)**

## Install (30 seconds)

1. Open the Claude desktop app and click the **Code** tab.
2. Drag `first-skill-skill.md` in and type **set this up**.
3. Type `/first-skill`, or say: *Let's build my first skill.* Claude asks which task you do every day and takes it from there.

Works best when Gmail, Google Calendar or Google Drive are connected in Claude. Claude tells you if one is missing. The source is right here: [`SKILL.md`](SKILL.md).
